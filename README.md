# Семейный архив

Локальное генеалогическое древо для GitHub Pages. Опубликованные данные находятся в `public/data/family.json`; пользовательские изменения сохраняются только в браузере.

## Запуск

```bash
npm ci
npm run dev
```

## Обновление данных прямо на GitHub

1. Откройте файл `public/data/family.json` в репозитории.
2. Нажмите кнопку редактирования (карандаш).
3. Измените нужные поля. Сохраняйте уникальные латинские `id` и корректный JSON.
4. Измените `updatedAt` и увеличьте `version`.
5. Нажмите **Commit changes**.
6. GitHub Actions автоматически соберёт и опубликует новую версию Pages.

Второй способ: внесите изменения в приложении, нажмите **Резервная копия**, затем замените содержимое `public/data/family.json` скачанным файлом.

Если в браузере уже были локальные изменения, приложение продолжит показывать их. Нажмите кнопку со стрелкой **Вернуть опубликованные данные**, чтобы загрузить обновлённый файл с GitHub.

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` автоматически публикует папку `dist`. В настройках репозитория откройте **Settings → Pages → Source** и один раз выберите **GitHub Actions**.

## Приватность

GitHub Pages публичен. Не размещайте в `family.json` адреса, телефоны, документы, точные даты рождения живых людей и закрытые семейные сведения. Такие данные храните только локально или переходите на версию с авторизацией и закрытой базой.
